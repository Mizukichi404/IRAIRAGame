公平を装った実技試験です。右へ上へ進み、答案を提出すると合格です。

```bash
npm test
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173` を開きます。

歩くのは ← → または A D、跳ぶのはスペース、↑、Z、または画面を押します。落ちたあとは、もう一度スペースです。

## 出題

ジャンプの高さは毎回同じです。ランニングなら約167px、その場なら約92px。届かないのは乱数ではなく、踏み切りの位置です。

イライラが残るのは、次の仕掛けです。

- ニアミスは px で残る。あと数pxだと、原因が自分の操作に見える。
- 死亡数と経過時間は消えず、表紙に戻っても残る。
- 本当のセーブは地味で、派手なセーブは嘘。追加問題では見た目が入れ替わる。旗の軸にある点だけは、本物にしか付かない。
- 第1問のゴールは練習だったと後から告げられる。到達率は 99% で止まり、一度 100 になってから戻る。
- 最後の隙間は画面上「1mm」。計測は px。再試験は「同一問題」と言いながら、隙間だけ広い。
- 合格しても評価は別です。評価を取りに、もう一度受けられます。

棄権はいつでもできます。確認は一度だけです。
